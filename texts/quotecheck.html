quotecheck: checking that a quotation is in its source

A Python package that tells whether a quotation occurs in a source, tolerant of extraction noise but not of rewording; it reports ABSENT for a fabricated ISACA quotation and a sentence misattributed to Viktor Frankl.

Overwhelmed? Here's the short version
  • It compares a quotation with its source, ignoring case, ligatures, hyphens, accents and quotation marks.
  • It answers FOUND, FOUND*, DRIFT or ABSENT, and can check every quotation in a note.
  • Its accuracy has not been measured on a labelled set.
  • It can only judge a quotation against a source it has been shown.

What it does, and comparable tools

quotecheck answers one question: does this quotation occur in this source? It was written for a wiki that an agent keeps, which quotes its sources hundreds of times, after a fabricated quotation reached it. An agent reading the ISACA CISA Review Manual produced, as ISACA's own words, "a security audit does not typically test information security in an organization but just indicates the extent of compliance with standards". The manual does not contain that sentence. The clause "indicates the extent of compliance with standards" occurs once, in the other column of a two-column page: the manual is a 304 MB scanned PDF, and pdftotext -layout joins the two columns line by line into sentences that read well and never existed1. The sentence survived review in this case because it matched what the brief was looking for, the compliance profession criticising itself in its own credentialing text, so the strength of a claim was no guide to which quotations needed checking. In the wiki's own repository the checker's earlier form is the script quote.py (private; not verifiable).

General fuzzy matchers already find near-matches of a string in a text. Python's difflib scores the similarity of two sequences2, and RapidFuzz computes Levenshtein-based scores quickly, including a partial_ratio for the best-matching substring3. Work on citations in language-model output, such as the ALCE benchmark, asks a different question, whether a cited passage supports a generated claim, and answers it with a model4. quotecheck is narrower than either. It asks whether the words in quotation marks are in the source verbatim, it gives a named, ordered answer rather than a score, and it shows the reader only the source's original text, never the normalised form in which the match was found.

Method: folding, an offset map and four answers

Both the source and the phrase are folded to a comparison key: lower case, ligatures expanded, hyphens and dashes dropped on both sides, whitespace dropped, accents stripped and quotation marks removed. Each rule exists because of a genuine quotation that an earlier check called fabricated. The first check was grep, which reported three fabrications that were all real: one began a sentence and the check was case-sensitive, one was hyphenated across a PDF line break as vibra- tion, and one spanned a line break. Ligatures (tradeoﬀ stored as one glyph), accents (Niccolo typed for Niccolò) and nested quotation marks followed over the next days. Hyphens are dropped on both sides because a word such as cross-validation broken at its own hyphen at the end of a line cannot otherwise be matched both when it is typed with the hyphen and without it. The fold keeps a map from every folded character back to its offset in the original, so the match is found on the key and the context is printed from the source5.

The four answers are tried in order of strictness. FOUND gives the count and the surrounding text. FOUND* means the phrase occurs as two adjacent halves, each at least twelve folded characters long, with at most twelve folded characters between them, which is what a page number or running head dropped into a sentence by a scan looks like. Digits are not folded away, because a changed year or count is a changed quotation, and a splice of two fragments from different parts of a book fails because the halves are not adjacent. DRIFT is reported when the phrase does not occur but a window of the source as long as the phrase, aligned on their longest common run of at least eight folded characters, has a similarity of at least 0.80, measured as difflib.SequenceMatcher.ratio() (twice the matched characters over the total characters of the two folded strings). The tool then prints what the source says, and drift counts as not found. Anything else is ABSENT. In batch mode the tool extracts every blockquote line and every quoted run of six or more words from a Markdown note and checks each one5.

Worked example: four books

$ quotecheck East-of-Eden/source.txt "For if Thou mayest—it is also true that Thou mayest not"
FOUND   1x  For if Thou mayest—it is also true that Thou mayest not
        …That throws it right back on a man. For if ‘Thou mayest’—it is also true that ‘Thou mayest not.’ Don’t you see?…

$ quotecheck mathsapology-hardy/source.txt "If a man has any genuine talent he should be ready to make almost any sacrifice"
FOUND*      If a man has any genuine talent he should be ready to make almost any …
        …If a man has any genuine talent he 4 should be ready to make almost any sacrifice in order to cultivate it to the full…

$ quotecheck CISA-Review-Manual/source.txt "a security audit does not typically test information security in an organization but just indicates the extent of compliance with standards"
ABSENT  a security audit does not typically test information security in an or…

$ quotecheck Mans-Search-for-Meaning/source.txt "Between stimulus and response there is a space"
ABSENT  Between stimulus and response there is a space

These four runs were made against the extracted full text of the four books and are reproduced as printed6. Steinbeck's sentence had been transcribed without its inner quotation marks and is found. Hardy's is found in two halves because the scan put a page number, 4, inside the sentence. The ISACA sentence is absent. So is the sentence most often attributed to Viktor Frankl, "Between stimulus and response there is a space. In that space is our power to choose our response", in the text of the Beacon Press edition of Man's Search for Meaning that was checked. Quote Investigator could not find it in Frankl's works either and traces its spread to Stephen R. Covey, who said he had read it in a book he could not identify7.

Tests and measured error

The package has 20 tests, run on Python 3.10 to 3.13 in GitHub Actions and passing locally on 29 September 2026. The fixture is a short invented source containing one instance of each false-alarm class, and the tests require each genuine quotation to be found, a reworded sentence to be reported as drift, a fabrication to be absent and a splice of two real fragments not to pass as FOUND*; the rest cover batch extraction and the command line5.

No error rate has been measured on a labelled set of quotations, so the tool's accuracy rests on these tests and the runs above. The larger checks in the wiki are part of its private log and cannot be verified outside it1. According to that log, after the ISACA fabrication all 292 quoted passages on the 15 CISA pages were checked by machine against the source on 27 August 2026, before this tool existed; about seven more passages had no matching run of words, though their substance could be traced in the source. The fabricated quotation was removed, the removal was recorded on its page, and every CISA page now carries a note that its terminology and structure are reliable and its verbatim sentences are not. On 28 August 2026 two agents asked to re-check their own finished pages found sixteen defects between them: one misquotation in the first person, one substituted conjunction and fourteen splices, two real fragments joined into a sentence the book does not contain. A splice passes any check made on a quotation before it is written, since both halves are in the source, which is why batch mode checks the finished page.

Limits

The tool needs the source as text and is only as good as the extraction. A two-column scan still produces sentences that read well and never existed, and the tool will find them, because they are in the text it was given. The drift threshold of 0.80 and the twelve-character gap were set by hand on these cases and have not been tuned or validated on other material. The tool does not judge whether a paraphrase is fair, only whether quotation marks were earned, and it says nothing about a quotation from a source it has not been shown.

Install and reproduce

The package installs with pip install quotecheck, has no required dependencies and reads plain text, Markdown, HTML, EPUB and PDF (through pdftotext when installed, or pip install "quotecheck[pdf]" for pypdf). A single check is quotecheck source.txt "phrase", and quotecheck source.txt --batch note.md checks a whole note. The four runs above cannot be reproduced from the repository, because the books are copyrighted and their text is not redistributed. The test fixtures in tests/ are the reproducible substitute: cloning the repository and running uv run pytest exercises every rule and answer described here5.
