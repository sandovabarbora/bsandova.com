  • 8 October 2026, code, before any spacing was read: tests on made-up data showed that the registered estimate of amplification, a shuffled comparison, keeps the bias that recording noise puts into it, because the shuffle also separates each change from its noise. The fixed effects are removed once and the bootstrap re-weights days; the shuffle check uses five shuffles.
