Changes after registration

The first three are dated in the design file and were made before any estimate was run. (1) The archives with records start in 2016, so the sample is ten autumns, and the power calculation led to dropping the evening and morning trends from the main model, which became a check. (2) Districts are recorded only from 2023, so the unit became the region. (3) The first run of the data step dropped every record whose minute was unknown, although its hour was known; this was corrected before any estimate. (4) The change note that made the region the unit said the district-level map of the design would stay; the published map is drawn by region instead, at each region's centroid. This one was not noted in the design file and is listed here after an audit. None changes the rule for reading the result.
