After a code review, still before any day was counted: a day whose files fail to parse in more than 0.5 % of cases stops the run; traces are put in time order first; only an HTTP 404 makes a release missing, other persistent failures stop the run; check 1 got a variant on the primary points; and a structure-only preflight ran on one Wednesday per study year.

The design sets no minimum number of days, so no rule was triggered; the years keep 51, 52, 48 and 32 days and the Q3 windows lose one day.
