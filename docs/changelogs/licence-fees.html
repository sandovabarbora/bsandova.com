  • 3 November 2026, before the code tag: the register's size bands coincide with the classes of the fee schedule, so the design's firm range is a single value and its plausibility test would always fail. Other resolutions where the design was silent: the inflation shock applies from 2026 on; a crossing in year Y raises the bill's amount from Y+1 only for 2028 and later; the composition rule of the living minimum; the annual ČNB value as the exact mean of four quarters; an E0 payer share above 1 left uncapped and flagged; empty budget cells read as 0 and listed; the seniors' cut today only.
  • 3 November 2026, implementation rule where the design was silent, fixed in the code before the code tag: a ratio with a denominator of 0 is read as above the "similar" band everywhere, since a positive amount over 0 grows without bound. It matters for the change label: with the poorest tenth exempt, Y = 0 and Z ÷ Y is undefined, while with nobody exempt Z ÷ Y is 0.45, below the band. Read as above the band or as similar, the undefined bound disagrees with the other, so the label is "depends on the assumption"; only reading it as below the band would give "lower after".
