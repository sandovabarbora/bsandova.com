Ask the site. It shows its work.

A small agent with four tools: list this site's data files, read a slice of one, search the texts, verify a quotation verbatim. Four rules it is scored on: every number comes from a tool result, every quotation is verified before it is quoted, it declines when the site has no such data, and every question has a cap and every day a budget. The trace, tools called, tokens, cost and the rule checks, is shown under each answer. It is deliberately small; the rules are the point, and they are the same rules the assistant at work runs on1.

How it is scored

Thirty golden questions with known answers, run against the live API by ask/eval.py, results below as they came back. Eighteen ask for a number in a data file, seven for something said in a text, one demands a verbatim quotation, and four should be declined: a phone number, a forecast for Christmas, a poem, a question about the assistant's own configuration. A question counts as correct when the expected value is in the answer, or when the right response is a refusal and it refused. Two protocol flags are computed from the trace, not from the text: a number stated without any tool result in the conversation, and a quotation without a verified quote call1.

Every evaluation

The golden set runs every Monday morning against the live API and appends one row here, so a change in the model, the prompt or the data files shows up as a change in the score, not as a quiet drift. Same idea as the model release watch, pointed at this site's own agent.

What it is not

Not a search engine over the web, not a chat about anything, and not a place where a wrong number can hide: the trace under every answer says which file was read. Four guardrails are enforced in code, not in the prompt: an answer produced without any tool call, a number without a tool result, code in the answer, or a quotation that was not verified is replaced by a refusal, and the trace says so. The one miss in the table above is the theme of this site in miniature: the agent read a text instead of the data file and attributed 2 745 stalls to the wrong series, confidently. The cross-check would have caught it; the golden set did. The model is the configured one in the trace, and the cost shown is computed from configured list prices, not from a bill. If today's budget is spent, it says so and the data files stay readable by hand. The Worker is about 200 lines with no framework; the source is in the repository1.
